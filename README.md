# Agentic Backlog MCP Server

Servidor MCP local-first para expor ferramentas de backlog para qualquer IA.

## Objetivo

- oferecer tools MCP para criar e atualizar tasks
- armazenar tudo em SQLite local
- integrar com o servidor de backlog Elysia

## Proximas tools

- `backlog.identify_project`
- `backlog.create_task`
- `backlog.list_tasks`
- `backlog.update_status`
- `backlog.add_note`
- `backlog.plan_from_context`
